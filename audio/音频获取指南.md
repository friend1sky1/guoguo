# 音频获取指南（自己录 / AI 生成）

目标：给 21 首儿歌 + 7 首晚安曲做"念读音频"，放进 `audio/` 文件夹就能播。
朗读要求（跟手册理念一致）：**慢、温柔、拖韵脚**，比平时说话慢一档。

---

## 方式一：AI 生成（最快，推荐先用这个跑通）

### 免费方案 A：edge-tts（微软免费语音，效果自然）
1. 电脑上打开终端（Win 按 Win+R 输入 cmd 回车）
2. 安装（只需一次）：`pip install edge-tts`
3. 生成一首儿歌（把歌词换成你要的）：
   ```
   edge-tts --voice zh-CN-XiaoxiaoNeural --rate=-15% --text "一闪一闪亮晶晶，满天都是小星星，挂在天上放光明，好像许多小眼睛。" --write-media song1.mp3
   ```
   - `--voice`：女声推荐 `zh-CN-XiaoxiaoNeural`（温柔）；男声 `zh-CN-YunxiNeural`
   - `--rate=-15%`：放慢 15%，念儿歌正好
   - 生成的文件就是 `song1.mp3`，放进 `audio/` 文件夹
4. 注意：`--text` 里只能放纯文本，标点保留没问题

### 免费方案 C：一键批量生成（推荐，跑一次出全部 28 首）
用 `audio/` 文件夹里的 `generate_audio.py`，歌词已经全部内置：
1. 装 Python（python.org 下载安装，装的时候勾选 Add to PATH）
2. 命令行里装 edge-tts：`pip install edge-tts`
3. 在 `audio/` 文件夹里运行：`python generate_audio.py`
4. 等几分钟，28 个 mp3 全部生成，文件名自动对好，直接就能播

- 想换声音：打开脚本改第一行 `VOICE`（男声 `zh-CN-YunxiNeural`）
- 想更快/更慢：改 `RATE`（如 `-10%`、`-20%`）
- 想先试一首验证流程：把 `SONGS` 列表临时只留第一行再运行

### 免费方案 B：网页版 TTS（不用装东西）
- 剪映（手机/电脑）：文本朗读 → 选温柔女声 → 导出音频
- 豆包 / 讯飞星火 App：文字转语音，选儿童/温柔音色
- 导出 mp3 后改名为 `songX.mp3` 放进文件夹

## 方式二：自己录（最贴合"真人声音才是核心"的理念）
- 手机自带录音机，或者用微信"语音备忘录"
- 录完导出/发送到电脑，转成 mp3（格式工厂 / 剪映都可转）
- 命名：`song1.mp3`、`lul1.mp3` 这样的规则不变
- 建议：录的时候家里安静、语速放慢、每句之间留半拍——这就是给果果的"专属声音"

---

## 常见问题
- **命名错会怎样**：播放按钮会自动隐藏（没找到对应文件），不影响别的功能，改对名字就出现
- **版权提醒**：网上直接下载的儿歌 mp3 部分有版权，个人家用风险小、发布到网上有风险；自己录或 AI 生成最稳
- **格式**：优先 mp3；m4a 在安卓上可能不兼容，尽量转 mp3
