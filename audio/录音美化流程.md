# 录音美化流程（手机版 · 照着点就行）

目标：把自己唱/念的儿歌、晚安曲，修好音准、去掉杂音、加一点温柔感，导出 mp3 放进 `audio/` 文件夹。

**先说结论：一共三步——录唱 → 全民K歌修音准 → 剪映美化导出。**

---

## 第 0 步：先录一首试通流程

别一次录 28 首。先录《小星星》，把下面的流程走一遍，放进 `audio/` 文件夹，刷新网站点 ▶ 听效果。满意了再批量录。

---

## 第 1 步：录唱

1. 找安静房间（关窗、关电视、手机静音）
2. 手机**自带录音机**（或微信 → 发语音给自己，但录音机更清晰）
3. 嘴离手机 15~20 厘米，别太近（太近会喷麦）
4. 语速放慢，每句之间留半拍——念儿歌就是这样
5. 唱错不用重录整首，**等唱完**，后面修音准能拉回来大半

---

## 第 2 步：全民K歌（或唱吧）修音准

1. 手机装 **全民K歌**（免费）
2. 首页 → 点 **"点歌"** 或 **"K歌"**
3. 搜索框输入歌名（《小星星》《两只老虎》这些都有伴奏）
4. 进到演唱页 → 右上角/底部找 **"调音"** 或 **"均衡/音效"** 按钮（麦克风图标旁边）
5. 打开 **"智能修音"**（有的叫"一键修音/美化"）——跑调的地方自动拉回
6. 点 **"混响"** 选 **"轻混响"** 或 **"录音棚"**（别选"演唱会"，太重）
7. 唱完点 **"完成"** → 保存

> 如果找不到对应伴奏（比如《摇篮曲》冷门），就用**第 1 步录的干声**直接进第 3 步，跳过修音准。

---

## 第 3 步：剪映 美化 + 导出

1. 手机装 **剪映**（免费）
2. 打开剪映 → **"开始创作"** → 选一张纯色图（或什么都不选，直接"导入音频"）
3. 底部工具栏点 **"音频"** → 导入你录好的/全民K歌导出的声音
4. 选中音频轨道 → 底部出现菜单，点 **"变声/声音美化"** 旁边的 **"人声美化"**：
   - **音色**：往"温暖/圆润"方向拉一点（别拉满）
   - **降噪**：打开（环境噪音自动去掉）
   - **混响**：加一点点（10~20%），让声音不干
5. 预览听一遍，满意后点右上角 **"导出"**
6. 导出设置里 **分辨率选最低的 480P**（音频为主，省空间），点导出
7. 导出的是 mp4——**把文件名后缀改成 .mp3 不行**，要用"提取音频"：
   - 剪映导出的视频，用 **"格式工厂"**（电脑）或手机 **"MP3转换器"** App 把视频转成 mp3
   - 或者更省事：剪映里导出前，用 **"仅导出音频"**（部分版本有）；没有就用转换 App

---

## 第 4 步：命名放进文件夹

1. 文件名改成对照表的名字（`song1.mp3` = 小星星，见同文件夹 `说明.txt`）
2. 放进去：电脑直接拖进 `audio/` 文件夹；手机的话用微信"文件传输助手"发到电脑再放
3. 刷新网站 → 对应儿歌卡片右上角出现 ▶ → 点它试听

---

## 常见问题

- **听起来太"电音"**：人声美化/混响都拉过头了——调到"能听出是你自己"的程度最好，宝宝要的是熟悉感，不是音效
- **伴奏和原唱版权**：个人家用没事，别发到公开平台
- **不想下载 App**：直接录干声 → 剪映美化 → 导出，也完全能用，只是少了一步修音准

---

## 电脑党进阶（可选，以后有空再学）

- **Audacity**（免费开源软件）：录音 → 降噪（效果 → 降噪 → 获取噪声样本 → 再降噪）→ 均衡（提升 1-2kHz 人声频段）→ 混响（效果 → 混响，轻一点）→ 导出 mp3
- 上限更高，但手机流程已经够用
